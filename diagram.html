ai-sandbox command map

What each ai-sandbox-admin command does to a tool, using Claude Code at ~/.local/bin/claude as the example. There is no separate edit command: you edit tools.conf by hand, then run list.

Every change above is logged in actions.log with a backup, so ai-sandbox-undo last reverses the most recent command and ai-sandbox-undo all reverses everything back to before install.
